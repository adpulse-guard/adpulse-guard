CORE DETECTIONS

From request to render.

Browser-side observation of GPT, DOM and ad-slot behavior, without making ad delivery changes.

Delivery signals

Were ad requests sent and responses received?

  • GPT missing or inactive
  • No slot requests
  • Requested slot missing DOM
⚙

Configuration

Are ad slots configured correctly?

  • Wrong GAM network ID
  • DOM slot not registered
  • Unexpected rendered size

Rendering & context

Did the ad render as expected?

  • Empty ad response
  • Collapsed container
  • Visibility / layout issues
